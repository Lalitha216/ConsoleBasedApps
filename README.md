# 🎮 Tic-Tac-Toe Game Using Java

## 📌 Project Overview

Tic-Tac-Toe is a console-based two-player game developed using Java. The game allows two players to take turns marking X and O on a 3×3 game board. The player who successfully matches three symbols horizontally, vertically, or diagonally wins the game.

## 🛠️ Technologies Used

- Java
- Core Java
- 2D Arrays
- Scanner Class
- Loops
- Conditional Statements
- Methods

## ✨ Features

- Two-player gameplay (Player X and Player O).
- Interactive 3×3 game board.
- Row-wise winning condition checking.
- Column-wise winning condition checking.
- Diagonal winning condition checking.
- Invalid move validation.
- Prevents selecting already occupied cells.
- Automatic player switching.
- Draw detection.
- Displays the winner or draw result.

## ⚙️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in Eclipse, IntelliJ IDEA, or VS Code.

3. Open the `TicTacToe.java` file.

4. Run the Java application.

5. Enter row and column positions between 0 and 2 when prompted.

## 🎯 Game Rules

1. Player X starts the game.
2. Player O takes the next turn.
3. Players must enter row and column positions between 0 and 2.
4. Each player must select an empty cell.
5. The first player to match three symbols in a row, column, or diagonal wins.
6. If all nine cells are occupied without a winner, the match ends in a draw.
